# Customer Trend Prediction in Beauty & Wellness Industry

## About the Project
This project focuses on understanding customer preferences and predicting product trends in the Beauty and Wellness industry using Data Science and Python.

## Problem Statement
Beauty companies often face difficulties in understanding changing customer preferences and predicting future product demand.

## Objectives
- To understand customer buying preferences.
- To identify popular beauty product categories.
- To study customer ratings and reviews.
- To understand factors affecting product demand.
- To explore data science techniques for trend prediction.

## Tools and Technologies
- Python
- Microsoft Excel
- Pandas
- Matplotlib

## Project Scope
This project aims to analyse publicly available data related to beauty products, customer reviews, ratings and prices.
